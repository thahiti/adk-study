## 1.36.2에서 확인한 사실

- `output_key="k"`를 준 LlmAgent는 최종 텍스트를 `actions.state_delta={"k": 텍스트}`로 실어 보낸다.
- instruction의 `{k}`는 state 값으로 치환된다. 키가 없으면 `KeyError('Context variable not found: ...')`가 난다. `{k?}`로 쓰면 없을 때 빈 문자열이 된다.
- 모델에 가는 system_instruction은 instruction 뒤에 `You are an agent. Your internal name is "..."` 문장이 덧붙는다. 테스트는 포함 여부만 검사한다.
- 도구 함수에 `tool_context: ToolContext` 인자를 두면 `tool_context.state`로 읽고 쓸 수 있다. 쓴 값은 function_response 이벤트의 `actions.state_delta`에 실린다.
- 접두어 없는 키는 세션에만 남는다. `user:` 키는 같은 app_name과 user_id의 새 세션에서도 보인다. `app:` 키는 같은 app_name의 모든 사용자 세션에서 보인다. `temp:` 키는 이벤트 delta에서 제거되어 저장되지 않는다.
- InMemorySessionService의 `create_session`이 돌려주는 세션 state에는 `app:`과 `user:` 키가 병합되어 있다.
- SequentialAgent는 sub_agents를 순서대로 실행하고, 앞 에이전트의 output_key 값이 뒤 에이전트 instruction의 `{k}`에 치환된다. 두 에이전트의 이벤트는 invocation_id가 같다.

async def run_in_session(
    runner: Runner, session: Session, text: str
) -> list[Event]:
    """이미 있는 세션에 사용자 메시지 한 개를 보내 이벤트를 모은다."""
    message = types.Content(
        role="user", parts=[types.Part.from_text(text=text)]
    )
    return [
        event
        async for event in runner.run_async(
            user_id=session.user_id,
            session_id=session.id,
            new_message=message,
        )
    ]


async def run_turn(
    agent: BaseAgent,
    text: str,
    *,
    app_name: str = "test",
    user_id: str = "user",
) -> list[Event]:
    """새 세션을 만들고 사용자 메시지 한 개를 보내 이벤트를 모은다."""
    runner = InMemoryRunner(agent=agent, app_name=app_name)
    session = await runner.session_service.create_session(
        app_name=app_name, user_id=user_id
    )
    return await run_in_session(runner, session, text)
```

from google.adk.runners import InMemoryRunner

from adk_study.testing import FakeLlm, run_in_session, run_turn, text_reply

async def test_final_event_carries_answer_in_state_delta():

"""state_02_tool_context: 도구가 state 를 읽고 쓴다."""

from google.adk.agents import LlmAgent
from google.adk.tools import ToolContext

from adk_study.models import make_model


def bump_counter(tool_context: ToolContext) -> int:
    """세션의 count 를 1 올리고 새 값을 돌려준다."""
    count = tool_context.state.get("count", 0) + 1
    tool_context.state["count"] = count
    return count


root_agent = LlmAgent(
    name="state_counter",
    model=make_model(),
    description="부를 때마다 카운터를 올리는 에이전트",
    instruction="사용자가 올리라고 하면 bump_counter 도구를 쓰고 새 값을 "
    "한국어로 알려 준다. 직전 답: {last_answer?}",
    tools=[bump_counter],
    output_key="last_answer",
)
```

# state_02_tool_context

## 이 단계가 보여주는 것

- 도구 함수에 `tool_context: ToolContext` 인자를 두면 ADK 가 자동으로 채워 준다.
  이 인자는 모델에 보내는 스키마에 들어가지 않는다.
- `tool_context.state` 는 읽으면 현재 세션 state 이고, 쓰면 delta 에 쌓인다.

def bump_then_answer() -> FakeLlm:

async def bump(runner: InMemoryRunner, user_id: str):
    """user_id 로 새 세션을 만들어 한 번 올리고 저장된 세션을 돌려준다."""
    session = await runner.session_service.create_session(
        app_name="test", user_id=user_id
    )
    root_agent.model = bump_then_answer()
    events = await run_in_session(runner, session, "올려")
    stored = await runner.session_service.get_session(
        app_name="test", user_id=user_id, session_id=session.id
    )
    return events, stored


async def test_temp_key_is_dropped_from_delta_and_state():
